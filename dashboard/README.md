# Shahed Detection Dashboard

Static review interface for real detector output on video clips.

Open `index.html` in a browser, or run a local server from the repository root:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/dashboard/`.

The dashboard starts empty. Open a video, then open the detections JSON generated by
`scripts/run_inference.py`.
