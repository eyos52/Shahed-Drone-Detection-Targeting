# Shahed Detection Dashboard

Review interface for real detector output on video clips.

Run the local Python backend from the repository root:

```bash
source .venv/bin/activate
python server.py
```

Then visit `http://127.0.0.1:5000/`.

The dashboard starts empty. Open a video, then click **Run model**. You can also open an
existing detections JSON generated by `scripts/run_inference.py`.
